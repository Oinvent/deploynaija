How to Setup cPanel for Agentless Deployments

1 Enable SSH Access in cPanel

Log into your cPanel account (e.g. QServers, Whogohost). Navigate to Security > SSH Access and ensure SSH is enabled for your account.

2 Add Public Key

Click Manage SSH Keys > Import Key. Paste the generated DeployNaija Public Key into the Public Key text area and click Import.

3 Authorize Key

In the key list, click Manage next to the newly imported key and click Authorize. This allows passwordless SFTP/SSH deployment.

4 Custom SSH Ports in Nigeria

Standard SSH uses port 22. However, local hosters like QServers often use port 21098 or 4739. Make sure to specify the correct port in the form.
